Parakeet models
==============
Original models by NVIDIA, licensed under Creative Commons Attribution 4.0
International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/
https://creativecommons.org/licenses/by/4.0/legalcode.en

Parakeet TDT-CTC 110M (English):
https://huggingface.co/nvidia/parakeet-tdt_ctc-110m

Parakeet TDT 0.6B v3:
https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3

The ONNX exports and int8 quantized variants are distributed for sherpa-onnx:
https://github.com/k2-fsa/sherpa-onnx
https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models

Cassini obtains the two int8 models from the sherpa-onnx release. The fp32
model is Cassini's own ONNX export of NVIDIA's original checkpoint; the files
published here are its only distribution.
For this distribution, Cassini compresses each model file independently using
seekable Zstandard. Decompressed file contents are
unchanged. ONNX conversion and int8 quantization are changes from NVIDIA's
original model format. No endorsement by NVIDIA or sherpa-onnx is implied.

Nemotron 3 Diarization
======================
Original model by NVIDIA, licensed under the OpenMDW License Agreement,
version 1.1 (OpenMDW-1.1):
https://huggingface.co/nvidia/Nemotron-3-Diarization
(revision f667ed73aee57d40cc39428eb768b4fd87a0a29e)
https://openmdw.ai/license/1-1/

Cassini exported the model to ONNX and quantized it to int8 with the
sherpa-onnx export script (scripts/nemo/nemotron-3-diarization, from
k2-fsa/sherpa-onnx#4006). Each model file is compressed independently using
seekable Zstandard; decompressed contents are the exported files.
ONNX conversion and int8 quantization are changes from NVIDIA's original model
format. No endorsement by NVIDIA or sherpa-onnx is implied.

EmbeddingGemma 2
================
Original model by Google DeepMind, licensed under the Apache License,
version 2.0 (Apache-2.0). The model card links its licence as
https://ai.google.dev/gemma/docs/gemma_4_license, which is the Apache License
2.0 text reproduced below. Google's Gemma prohibited use policy is guidance:
https://ai.google.dev/gemma/prohibited_use_policy
https://huggingface.co/google/embeddinggemma-2
(revision 914f7f89142e33e77833254d9c9b90c3cef7303b, tokenizer.model)

The text model's int8 ONNX export is the onnx-community conversion:
https://huggingface.co/onnx-community/embeddinggemma-2-ONNX
(revision daa72c51243991dfcaf9f9137d2c573d8f7790c0, onnx/model_quantized.onnx
and onnx/model_quantized.onnx_data)

Each file is compressed independently using seekable Zstandard; decompressed
contents are the upstream files. ONNX conversion and int8 quantization are
changes from Google's original model format. No endorsement by Google or the
onnx-community authors is implied.
