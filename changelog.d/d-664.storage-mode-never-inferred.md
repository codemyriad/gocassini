### Changed
- Cassini no longer works out its storage mode from the instance. It reads the mode it recorded, or the `CASSINI_STORAGE_MODE` deploy option, or falls back to the default model — and never infers "this Nextcloud has a Team folder, so it must want access control". Inferring made who can read the archive depend on what Nextcloud happened to look like at one instant, and on an instance still being set up that instant is the wrong one. An installation whose storage does not match its mode is now reported as a mismatch that refuses to publish, and says both ways out: the Setup tab, or the deploy option. A recorded mode is authoritative for the life of the install; nothing re-opens it.
