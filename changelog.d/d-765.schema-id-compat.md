### Fixed
- Meetings published before the format moved to format.gocassini.com open again. Every reader (viewer, `cassini meetings`, `cassini inspect`, the static export) refused those files with `unsupported CASSINI_PAYLOAD_SCHEMA` because they compared the tag against the new identifier only; they now accept the pre-move `cassini-format.codemyriad.io` identifier for the same version 1 schema. New files keep the current identifier.
