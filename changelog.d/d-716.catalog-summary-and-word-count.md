### Added
- The published meeting index (`catalog.json`, and so `cassini meetings list --json`) now records whether each meeting carries a summary and how many words its transcript holds. Both come out of the file the publish step already reads, so anything listing meetings can say which of them have a summary, and size a selection of them, without downloading a single recording. Meetings published before this update carry neither field, which reads as "not known" — never as "no summary" or "no words"; republishing one fills them in.
