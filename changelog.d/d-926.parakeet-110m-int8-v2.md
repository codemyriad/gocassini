### Changed

- CPU transcription at **Fast** is more accurate and about twice as fast (`parakeet-tdt-ctc-110m-en-int8-v2`). On a CPU, Cassini uses a shrunk-down copy of the English speech model so that it fits in memory and runs quickly. The `sherpa-onnx` project found a better way to shrink this kind of model so that it keeps more of the full model's accuracy. We applied that method and ship a new model (~101 MB download, 0.6 MiB larger on disk). Upgraded servers download the new model automatically and transcribe with the previous model until the new one is ready (~126 MiB each on disk until Cassini removes the old folder). If your server has no internet access, run `cassini models pack` on a connected machine, then `cassini models import` on the server. If you roll back to an older Cassini release after the upgrade completes, you must download the previous model again.
