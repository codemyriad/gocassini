### Added
- Cassini now tries to create the `cassini` service account and its group itself when the app is enabled, so an install whose Nextcloud allows that write records without anyone opening a setup screen.

### Changed
- When Nextcloud refuses that request, which is what Nextcloud 34.0.2 and later do, the account is reported as the one remaining prerequisite and an administrator's browser creates it from Cassini. Cassini does not retry it.
- A refused user or group creation is now judged on the OCS response body rather than the HTTP status, so a refusal that arrives as `HTTP 200` is no longer reported as an account that was created.
