### Changed
- The native speech runtime moves to sherpa-onnx 2.0.1 (Cassini's `v2.0.1-cassini` libraries on Linux, macOS and Windows, and the matching CUDA build). Quiet speech is now handled by upstream's own fix instead of Cassini's patched frontend. New transcripts change slightly: about 5% of words differ from the same recording transcribed before, with the same accuracy overall (meeting test set, word error rate: Parakeet Ultra int8 on CPU 9.24% against 9.18%, Ultra fp32 on GPU 7.92% against 7.31%; neither difference is significant, and the GPU one comes from a single passage of one meeting). GPU builds take about 22% longer. Existing transcripts are not re-transcribed, and no model is downloaded again. "Separate voices" gives the same speaker turns as before.
- Transcript provenance now records the speech frontend as `nativeFrontend: "nemo-log-guard"` instead of `referenceFrontend`, doctor names that frontend, and the operator's `/status` reports `stt.runtime_supports_model` instead of `stt.reference_frontend`. A recorder that finds an older (1.13.7) sherpa library on its library path refuses to transcribe and says so, instead of running it with mismatched structures.
- The GPU (`-cuda`) image moves from CUDA 12.4 to CUDA 12.9, which the new runtime needs to use the GPU. The host's NVIDIA driver must support CUDA 12.9: version 575 or newer (data-centre GPUs also on the 535, 550, 560, 565 or 570 branches). Check with `docker run --rm --gpus all nvidia/cuda:12.9.1-base-ubuntu22.04 nvidia-smi`.
