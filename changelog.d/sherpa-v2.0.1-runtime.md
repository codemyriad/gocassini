### Changed
- The native speech runtime moves to sherpa-onnx 2.0.1 (Cassini's `v2.0.1-cassini.1` libraries on Linux, macOS and Windows, and the matching CUDA build). Quiet speech is now handled by upstream's own fix instead of Cassini's patched frontend. New transcripts change slightly: about 5% of words differ from the same recording transcribed before, with the same accuracy overall (Parakeet Ultra int8, meeting test set: 9.33% word error rate, against 9.18%, a difference within noise). Existing transcripts are not re-transcribed, and no model is downloaded again. "Separate voices" gives the same speaker turns as before.
- Transcript provenance now records the speech frontend as `nativeFrontend: "nemo-log-guard"` instead of `referenceFrontend`, doctor names that frontend, and the operator's `/status` reports `stt.runtime_supports_model` instead of `stt.reference_frontend`. A recorder that finds an older (1.13.7) sherpa library on its library path refuses to transcribe and says so, instead of running it with mismatched structures.
