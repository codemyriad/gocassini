### Fixed
- `backfill-nc-files` now refuses to run on an installation using the default storage model, instead of writing access rules into a folder where they mean nothing. Everything it writes is protected by Team-folder permissions, and the default model keeps recordings in the `cassini` account's own folder where every signed-in account can already read them — so the migration was at best a no-op with side effects, and at worst re-derived an audience for recordings an administrator had deliberately left open. The refusal names the mode, writes nothing, and points at the Setup tab, which is what actually moves an archive between the two models.
