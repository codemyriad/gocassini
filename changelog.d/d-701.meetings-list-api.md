### Added
- Cassini now answers `published/meetings-list` with the meetings the calling account may read, narrowed by an optional date range or room. The viewer and the `cassini meetings` CLI previously fetched the whole catalogue and filtered it themselves; the same list is now available already filtered, in the catalogue format both already read.
- A date-filtered list reports how many meetings it dropped because their published date could not be read, so a short list is visibly partial rather than quietly incomplete.
- Unlike the catalogue it is built from, this list never answers an unreachable Nextcloud with an empty result: a substrate failure is reported as an error, and an empty list means only that the account may read no matching meeting.
