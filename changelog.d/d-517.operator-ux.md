### Changed
- Reworked the Cassini operator panel for the in-Nextcloud audience it is now shown to: the recordings list and run detail fill the available height as a master/detail pair, starting a recording is an on-demand composer rather than a permanently parked URL field, and the API-implementation captions (proxy paths, `GET /jobs`, `PUT /settings`) are replaced with plain descriptions.
- Rebuilt the connection indicator to state the connection first. A one-word status pill (Live / Connecting / Reconnecting / Offline) carries the state, with the refresh cadence beside it, replacing the previous "auto-refreshing every 2s" label that never said whether the panel was connected. Polling under AppAPI reads as Live because the data is current; only a genuine disconnect is styled as a fault.
- Restyled the transcription settings as three matching sections (detected hardware, quality, device/model overrides), condensed the quality options to one row each, and made the selected option legible instead of a near-invisible tint. The three sections sit side by side on wide screens at a common height, and the device/model overrides are no longer hidden behind a collapse.
- Made the recordings list and run detail a drill-down on narrow screens, and put the selected run in the URL so it can be linked to and the back button returns to the list.
- Grouped each run's attempts into collapsed accordions so a run with a long retry history opens at a readable summary rather than a wall of fields.
- Gave the recordings list its own scroll region on desktop, so a year of recordings fills the panel instead of stretching the page.

### Fixed
- Fixed Nextcloud's app chrome applying twice on the AppAPI embedded page, which added a second header-height gap, doubled the side margins, and clipped the bottom of the app.
- Fixed the shell tab bar and the operator scrollbar gutter rendering with light-mode colours in dark mode.
- Fixed the detected-hardware values being unreadable under some theme combinations.
- Fixed the settings Save button offering to save when nothing had changed.
- Fixed every `border`, `shadow-*` and `ring-*` utility rendering as nothing in the embedded Nextcloud build. Tailwind v4 resolves these through `@property`-registered custom properties, which only register from a document stylesheet — the embedded build links its stylesheet inside the shadow root, so the registrations were dropped and the values fell back to `none`.
- Fixed high-contrast themes leaving panels and cards without the outlines that define them, now that borders render at all, and stopped the run cards outweighing the panels around them.
- Fixed the selected run being unmarked in high-contrast themes, where the base-100/base-200 fills collapse to one colour; it now inverts foreground and background like the shell's active tab.
- Fixed the device and model override fields showing no usable border, and carrying a heavier inset edge than the quality options beside them.
