### Changed
- Reworked the Cassini operator panel for the in-Nextcloud audience it is now shown to: the recordings list and run detail fill the available height as a master/detail pair, starting a recording is an on-demand composer rather than a permanently parked URL field, and the API-implementation captions (proxy paths, `GET /jobs`, `PUT /settings`) are replaced with plain descriptions.
- Rebuilt the connection indicator to state the connection first. A one-word status pill (Live / Connecting / Reconnecting / Offline) carries the state, with the refresh cadence beside it, replacing the previous "auto-refreshing every 2s" label that never said whether the panel was connected. Polling under AppAPI reads as Live because the data is current; only a genuine disconnect is styled as a fault.
- Restyled the transcription settings as three matching sections (detected hardware, quality, device/model overrides), condensed the quality options to one row each, and made the selected option legible instead of a near-invisible tint.

### Fixed
- Fixed Nextcloud's app chrome applying twice on the AppAPI embedded page, which added a second header-height gap, doubled the side margins, and clipped the bottom of the app.
- Fixed the shell tab bar and the operator scrollbar gutter rendering with light-mode colours in dark mode.
- Fixed the detected-hardware values being unreadable under some theme combinations.
- Fixed the settings Save button offering to save when nothing had changed.
