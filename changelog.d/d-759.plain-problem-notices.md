### Changed
- **The "Cassini is not set up yet" page is now two sentences and two buttons.** When recordings cannot be saved, Cassini says so ("Cassini can't save recordings right now"), says what it costs ("Calls will still run, but their recordings will fail until this is fixed."), and says why in plain words, with "Try again" and "Show details" beside it. Try again re-runs the same check a restart runs.
- **The step name, the `occ` recipe, how to invoke `occ`, the operator's own sentence and the link to the full report all moved into "Details for administrators"**, a disclosure that starts closed. Nothing was dropped, and no enum name or command is in the opening sentences any more.
- **The cause of a failure is written by the operator, one sentence per check**, so `/status` and the app say the same thing about the same failure. `recordings_access` on `/status` gains a `cause` field; `/setup` gains one too, in the form that names no account, no path and no app.
- **A notice about a check that has not run yet is no longer drawn as a warning.** After a container restart, Cassini says it has not checked that it can save recordings, in a neutral band, and the meeting list stays where it is.
- **Someone who is not an administrator gets the same first sentence and nothing else**, plus the link to hand to somebody who can act.
- Steps that said "Open the Setup tab" now say "Open Operator › Settings", which is where those controls are.
