### Changed
- `cassini meetings list` now asks the app to filter by date and room, instead of downloading the whole catalogue and narrowing it locally. Against an app that does not offer that yet, it falls back to the previous behaviour, so an older CLI and a newer one both keep working.
- `cassini meetings list`, `rooms`, `fetch` and `context` now report an unreachable recordings archive as a failure rather than as an empty result. Previously an outage was indistinguishable from "this account has no recordings" — or, when fetching by id, from "no recording you can read at that id".

### Fixed
- Filter values no longer appear in `cassini meetings` error output. The request URL is printed when a call fails, and its query string was not being masked.
