### Removed
- The LLM readable-transcript cleanup step, which was shelved. Transcripts publish as transcribed, with speaker attribution and paragraph breaks but no model rewriting the words. Gone with it: `CASSINI_READABLE_STRICT_BATCHES`, the `--strict-readable-cleanup` build flag, the `cassini-readable` component, and the `transcript.readable.v1.json` producer. Meeting summaries are unaffected and remain the only LLM step in the pipeline. Files that already carry a readable transcript still open: the portable format keeps reading them.

### Changed
- `captions.vtt` is now always produced, from the transcript itself. It used to exist only when an LLM endpoint was configured, as a by-product of cleanup.
