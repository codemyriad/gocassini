### Changed
- **Graceful degradation on unpatched sherpa-onnx runtime.** Parakeet v3 speech
  transcription no longer halts when running against an upstream or unpatched
  `libsherpa-onnx-c-api` runtime. Instead of failing recognizer initialization,
  Cassini logs an informative warning, gracefully falls back to the standard
  decode profile (`defaultVADDecodePolicy()`), and records `referenceFrontend: false`
  in provenance metadata. This keeps transcription available when the reference frontend
  is absent.

### Added
- Cassini `doctor` and the operator `/status` diagnostic endpoint now verify
  the native speech engine runtime and report whether the Parakeet v3 reference
  frontend optimization (`+cassini-parakeet-v3-reference-v1`) is active. If an
  unpatched library is detected, a non-blocking warning is reported with guidance
  on how to enable the optimized runtime.
