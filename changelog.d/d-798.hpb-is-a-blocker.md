### Fixed
- Cassini now tells you when Talk has no High Performance Backend, which stops recording entirely. It reads Talk's own signaling mode, so the problem shows up even before a test room or a recording credential is configured — it used to be discoverable only by a connection check that never got that far. The row explains what is lost and links to Nextcloud's Talk documentation.
- The "Internal credential" row no longer ends with "HPB authentication is checked separately", which pointed at a check that does not happen on an installation without that backend.
