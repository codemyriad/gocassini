### Added
- `cassini annotate` reads and writes the tags and marks a recording carries inside its own `.opus` file. `show` prints them. `apply` takes a batch of edits — tag the whole meeting or a stretch of it, remove a mark, remove a tag, undo everything one run added, rename a tag — and rewrites the file once, without touching the audio, the transcripts or the summary. Sending the same batch twice changes nothing the second time, and a batch that changes nothing does not rewrite the file.
- `cassini annotate carry` moves the marks from a delivered recording onto a newly sealed one, so re-running a meeting does not lose them. When the new recording's audio differs, the marks are kept and flagged as made against different audio rather than redrawn on it.
