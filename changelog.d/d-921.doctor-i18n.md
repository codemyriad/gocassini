### Added

- Operator › Doctor is now translated too: each check's message, the steps to fix it, and the reason a recording could not get its recording time. Raw errors from Nextcloud and the system stay in English, so they can be searched for and quoted in a bug report.
- `/operator/status` and the readiness checks also send the values each message is built from (`params`), an `id` on each remedy step, and a `reason_code` with `reason_params` for a blocked recording. The English text is still sent.
