### Changed
- One person's imports no longer wait behind another person's whole queue. Each person's imports run one at a time, in the order they were added, and the server runs up to three imports at once across everyone.
- The Import sheet now says whether an import is waiting for the server, queued behind the person's own earlier imports ("Queued · 2 ahead"), or being fetched, checked or added. A queued import shows no progress bar.

### Fixed
- An import whose file stops downloading from Nextcloud Files now fails after two minutes without data, so it can be retried, instead of waiting until someone cancels it.
