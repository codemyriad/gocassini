### Added
- Published the Cassini agent skills as an installable package under `skills/`:
  `cassini-meetings` for finding and reading a recording, plus
  `cassini-meeting-summary`, `cassini-meeting-todos`, `cassini-meeting-shaping`
  and `cassini-meeting-retro` for turning a meeting into a summary, a
  grounded commitment list, a shaping draft or a retrospective. Install them
  into any agent that reads the Agent Skills format with
  `npx skills add codemyriad/gocassini`.
- Each workflow skill carries a versioned single-shot counterpart under
  `prompts/`, so the same artifact contract can be run by an agent or as one
  request against any OpenAI-compatible endpoint. The `v0` summarise prompt is
  byte-identical to the one the transcription pipeline embeds today.

### Changed
- Tightened the runtime skills around explicit user intent, source provenance
  and progressive disclosure. To-dos now distinguish accepted commitments from
  unconfirmed assignments, shaping no longer infers authority or alternatives,
  and retrospectives separate participant commitments from draft suggestions.
- Added `v1` single-shot prompt pairs for the tightened workflow contracts while
  preserving every `v0` file, including the summary bytes the product ships.
- Moved the `cassini-meetings` skill out of `.claude/skills/` and into `skills/`,
  so it is installable by any agent rather than only by Claude Code working
  inside this checkout.
