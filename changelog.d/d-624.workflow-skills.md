### Added
- Published the Cassini agent skills as an installable package under `skills/`:
  `cassini-meetings` for finding and reading a recording, plus
  `cassini-meeting-summary`, `cassini-meeting-todos`, `cassini-meeting-shaping`
  and `cassini-meeting-retro` for turning a meeting into a summary, a
  per-participant to-do list, a shaping draft or a retrospective. Install them
  into any agent that reads the Agent Skills format with
  `npx skills add codemyriad/gocassini`.
- Each workflow skill carries the single-shot prompt it runs as a versioned file
  under `prompts/`, so the same workflow can be run by an agent or as one
  request against any OpenAI-compatible endpoint. The summarise prompt is
  byte-identical to the one the transcription pipeline embeds today.

### Changed
- Moved the `cassini-meetings` skill out of `.claude/skills/` and into `skills/`,
  so it is installable by any agent rather than only by Claude Code working
  inside this checkout.
