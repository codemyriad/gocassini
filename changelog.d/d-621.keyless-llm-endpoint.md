### Added
- Recorder env knobs for self-hosted models: `CASSINI_READABLE_DISABLED` skips the readable-cleanup pass on its own (the summary twin, `CASSINI_SUMMARY_DISABLED`, already existed), `CASSINI_LLM_TIMEOUT_SEC` (default 900) and `CASSINI_LLM_MAX_TOKENS` (default 4096) size requests for a slow local model. These configure the `cassini` process — `cassini build` and scripts — and are not ExApp deploy options.

### Changed
- A keyless OpenAI-compatible endpoint now switches on transcript cleanup and meeting summaries: `LLM_BASE_URL` alone is enough, and `OPENROUTER_API_KEY` is needed only when the endpoint requires one. Previously both had to be set, so a self-hosted model server silently produced raw transcripts and no summary. **On upgrade**, an install that had `LLM_BASE_URL` set without a key starts producing cleaned transcripts and summaries through that endpoint from its next build; installs with both set behave exactly as before.
- With no key configured the recorder omits the `Authorization` header entirely rather than sending an empty bearer token, which some self-hosted servers reject.
