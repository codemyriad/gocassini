### Changed
- A keyless OpenAI-compatible endpoint now switches meeting summaries on: `LLM_BASE_URL` alone is enough, and `OPENROUTER_API_KEY` is needed only when the endpoint requires one. Previously both had to be set, so a self-hosted model server silently produced no summary. **On upgrade**, an install that had `LLM_BASE_URL` set without a key starts producing summaries through that endpoint from its next build.
- With no key configured the recorder omits the `Authorization` header entirely rather than sending an empty bearer token, which some self-hosted servers reject. New request bounds for slow local models: `CASSINI_LLM_TIMEOUT_SEC` (default 900) and `CASSINI_LLM_MAX_TOKENS` (default 4096).
