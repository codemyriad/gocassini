### Added
- Cassini can now set itself up. Where it previously reported what was missing and left you a list of `occ` commands, the Setup tab offers to make the changes: the `cassini` service account and its group, the Team folder, its group mappings, advanced permissions, and the permission-manager delegation. It lists every change before it makes any of them, and performs them as you — Nextcloud asks you to confirm your password with its own dialog, and Cassini never sees, stores or sends it. The commands are still there for an administrator who would rather run them.
- The notice on the meeting list now leads with that offer instead of a recipe, so an administrator who lands on a half-configured instance is one click from a working one rather than one copy-paste from a terminal.

### Changed
- Installing the two Nextcloud apps is the one step Cassini still cannot take for you, and it now says so instead of implying otherwise. Nextcloud requires an administrator's password on that particular request, which Cassini declines to handle; it attempts the install through its own backend — which works on Nextcloud 32.x, 33.0.0–33.0.5, 34.0.0, and on any release where `allowed_no_password_confirmation_ranges` is set — and otherwise links you to Nextcloud's own Apps page, where that flow lives. When the App Store refuses, the message says plainly that Nextcloud reports the same error whether the app is unknown, incompatible or the store is unreachable, and that retrying inside five minutes will say the same thing.
- The `occ` recipe printed in the app and the documentation is now generated from the same plan the Setup tab executes, so the two cannot describe different setups.
