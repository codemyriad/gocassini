### Changed

- **The control panel names each recording after its conversation, not its call token.** Every row read `Call a1b2c3d4` — the opaque string from the end of the request URL, which says nothing about which conversation was recorded. Rows and the detail heading now show the Talk conversation's display name, falling back to the token for a non-Talk recording, one whose room-name lookup never completed, and anything recorded before this release.

### Added

- `GET /jobs` returns `room_name`, the conversation's display name as it was when the job ran. The operator now stores the room as real columns on the job rather than only inside its Talk binding, and recovers them for every recording it has already made, so a room-scoped question is an ordinary query. The conversation's **token** is deliberately not returned: for a public conversation the token is also the link that joins it, so what leaves the operator stays a one-way derivation of it.
