### Changed

- **The control panel names each recording after its conversation.** A recording started from Talk showed as "Recording" — the trigger Talk sends carries the room's token and base URL rather than a call URL, and the panel only looked for a URL. One started by hand showed `Call a1b2c3d4`, its token. Rows and the detail heading now show the Talk conversation's display name wherever it is known, keeping the old labels as the fallback for a non-Talk recording, one whose room-name lookup never completed, and anything recorded before this release.

### Added

- `GET /jobs` returns `room_name`, the conversation's display name as it was when the job ran. The operator now stores the room as real columns on the job rather than only inside its Talk binding, and recovers them for every recording it has already made, so a room-scoped question is an ordinary query rather than a JSON parse. The conversation's token gets a column but is deliberately left out of the response, for the same reason the Talk binding has always been withheld from it.
