### Added
- `cassini meetings summarize <meeting.opus> ...` adds a meeting summary to already-published portable files without re-running transcription: the transcript sealed inside each file feeds one LLM call — configured by the same `LLM_BASE_URL` / `OPENROUTER_API_KEY` / `SUMMARY_*` variables as `cassini build` — and the file is rewritten in place with its audio bytes untouched.
- Files that already carry a summary are skipped; `--force` regenerates and replaces one, and `--out` writes a single file's result to a new path instead of in place. A backfilled summary is marked `provenance.meetingSummary.source = "backfill"` in the manifest.
