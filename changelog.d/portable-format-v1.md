### Changed
- Packed meetings now declare the published portable meeting format: `CASSINI_FORMAT=org.cassini.portable-meeting/1`, manifest `"version": 1`, and a `CASSINI_PAYLOAD_SCHEMA` that resolves — the schema is served at <https://cassini-format.codemyriad.io/>. The numbers this producer wrote before (`/1`, `/2`, `/3`) belonged to drafts that were never published outside Cassini, so version 1 is the first version anyone else can implement. Every file written so far still opens: readers now tell the shapes apart by what the manifest contains rather than by the version it claims.
