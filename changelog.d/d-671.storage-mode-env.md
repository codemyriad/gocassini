### Added
- A deployment can now declare which storage model a fresh install starts in, with the `CASSINI_STORAGE_MODE` deploy option (`default` or `access_controlled`). Left empty it behaves exactly as before — Cassini works the mode out from the instance and records it — but working it out is a reading of whatever Nextcloud looked like at that one instant, and on an instance still being assembled that instant is the wrong one. A declared mode is believed instead of guessed, and is treated as a choice: the correction that adopts access control on an instance whose substrate the first probe missed leaves it alone. It seeds the initial value only; the Setup tab is still where the mode changes afterwards, and changing the variable does not move an archive that already exists.
