### Added

- Administrators can write their own insight templates in Operator › Insight templates: start from a built-in template, change its instruction and output (for example, to write in Spanish), and save. A template that would not run is refused with the reason. Custom templates are kept on the app's volume, so they survive updates.
- Meeting summaries can use a custom template: choose it in Publish pipeline › Summary. Each summary records which template version wrote it.
- Everyone, not only administrators, can now choose the insight template when generating an insight.
