### Changed
- The native speech runtime is now sherpa-onnx `v1.13.7-cassini.8`. It applies the Parakeet reference frontend to Moondream Parakeet Ultra exports that keep their own model URL, and loads an export with the plain Ultra URL instead of exiting. Nemotron diarization is unchanged.
- macOS builds (Apple silicon and Intel) now use Cassini's own sherpa-onnx `v1.13.7-cassini.8` libraries, built and tested on GitHub runners, instead of the stock ones, so Parakeet Ultra, the Parakeet reference frontend and Nemotron diarization work there too; before, only the fast tier's 110M model transcribed. The Windows libraries are pinned to the matching Cassini release as well. Linux arm32 still uses the stock library.
