### Added
- The recording checks panel now also reports the machine Cassini runs on — disk space, ffmpeg, the speech runtime and the model cache — so a full disk explains a failed recording instead of leaving you guessing.
- Checks can now say that something is impaired rather than broken, shown in amber: a model that will download on first use is not the same as a missing one.

### Changed
- The operator's readiness endpoint is now `GET /operator/health`, because it reports on more than recording readiness. Upgrading an existing installation needs its AppAPI registration refreshed for the new route.
