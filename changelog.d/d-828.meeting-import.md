### Added
- You can now import portable meeting files into Cassini: a new Import tab in
  Browse takes dropped `.opus` recordings and transcription-only `.json`
  documents, shows what each file holds before uploading, and lets you choose
  per meeting whether to keep it to yourself or share it with selected people,
  groups and Teams (recipients may pass it along). Imported meetings list,
  play, search and tag like any recording, and retention manages them from the
  meeting's own dates.
- Operators can import from the server with `cassini-operator import-meeting`,
  which replaces the manual move-and-share runbook for old archives and backup
  restores.
