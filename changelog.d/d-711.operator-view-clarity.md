### Fixed
- **Routine recording stops no longer trigger an error banner in the operator view.**
  Successful runs with exit code 0 and normal stop reasons do not display the red error alert with internal runtime cancellation messages. The view displays an error alert only when a run or attempt actually fails.
- **Recordings from Nextcloud Talk display the call room token.**
  The operator view reads the Talk base URL and room token from the trigger request. Sidebar cards and run details now show the call token and a direct link to the room instead of generic placeholder text.

### Changed
- **Stop reasons and recording durations appear in run metadata.**
  The operator view formats raw reason codes into plain labels and displays the total recorded duration in sidebar cards and detail panes.
