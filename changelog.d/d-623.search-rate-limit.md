### Added
- Searches are rate limited per account. Each one asks Nextcloud what that person may read, so a client looping on search would put that load on Nextcloud rather than on Cassini; a burst is fine and a loop is asked to slow down, with a reply that says when to retry. The limit is per account, so one runaway client cannot lock anyone else out.

### Changed
- `cassini meetings search` says where a speaker id comes from — the `speaker=` value a previous result printed — so `--speaker` can actually be used. The ids are opaque and are not meant to be typed from memory.
