### Added
- Access control is now a choice rather than a requirement. Cassini used to have exactly one way to store recordings — a Nextcloud Team folder with per-recording permissions — which needs two Nextcloud apps an external app cannot install for itself, so an instance without them recorded meetings happily and then could not publish any of them. There are now two storage modes, switched in a new admin-only **Setup** tab: **default**, where recordings live in a `cassini` service account's own folder and everyone who can open Cassini can read all of them, needing no extra apps at all; and **access controlled**, which is exactly today's model. Switching either way moves the recordings that are already published, and says how many it moved.
- The Setup tab and `GET /operator/status` now name every missing prerequisite together with the `occ` command that fixes it — the service account, each Nextcloud app, the Team folder, its group mappings, its ACL setting and its ACL manager.

### Changed
- Cassini no longer creates Nextcloud accounts, groups or Team folders. On every enable it checks what is there and reports what is not, with the command to run; a half-built setup can no longer end up looking healthy. Existing installations are unaffected: an instance whose Team folder, service account and apps are already in place keeps working exactly as before, and keeps access control on — the mode is worked out once from the instance and recorded, and an upgrade never widens an archive on its own.
- Talk now refuses to start a recording when the storage it would be published to is missing a named prerequisite, instead of capturing the whole call and failing afterwards. The moderator sees Talk's own "The recording failed" message; the reason, and the command that fixes it, are in Cassini's Setup tab.
- The recordings-permissions, install and privacy documents now describe both modes. The upgrade section in particular had the Team-folder path collision backwards — a Team folder takes the `Cassini` path and Nextcloud renames the colliding home directory, rather than the mount being remapped — so its instruction to move the old folder out of the way first was unnecessary.
