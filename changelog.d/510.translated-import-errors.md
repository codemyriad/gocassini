### Fixed
- The Import sheet now says in the reader's language why a file was skipped: it is empty, larger than 4 GiB, not a meeting file from Cassini, made by a newer version of Cassini, or damaged or incomplete. The technical reason is still shown on hover. A file over 4 GiB is now refused before the browser tries to read it.
- A failed import now says what went wrong and what to do when the server knows: the file is too big to import right now (ask your administrator), the download from your Files stopped or the import took too long (try again), or the file is not a valid meeting file from Cassini. The server's own message stays behind Details.
- Refusals from the server that a person can meet in the Import sheet (busy, add the file again, still uploading, too late to cancel, larger than 4 GiB) are now shown in the reader's language instead of the server's English.
