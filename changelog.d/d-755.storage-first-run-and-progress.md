### Added
- The operator's storage API now says whether an install still owes its administrator the one-time dialog about who can see recordings. `GET /operator/storage` carries `first_run`, and `POST /operator/storage {"action":"acknowledge_first_run"}` answers it. The answer is recorded per install, so a second administrator or a second browser is not asked again, and an install that already has a recorded storage mode and recordings is never asked at all.
- A running storage-mode switch now reports its progress. While one is in flight, every `/operator/storage` response carries `migration` with the phase (`copying`, `verifying`, `switching`, `clearing`) and how many recordings of the total it has got through, so the switch stops being a request that blocks with nothing to show for it.
- `GET /operator/setup` now reports the storage mode in force, so people who are not administrators can be told who can see a recording. It is the name of a model and nothing else: no paths, no counts, no service account.
