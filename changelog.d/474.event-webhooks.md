### Added
- Added opt-in signed lifecycle webhooks for recording start/stop, build, summary completion/failure, publication, failure and share outcomes. A `summary.completed` event carries the summary Markdown from a normal build or a speaker-edit rewrite, so an external workflow can post it without polling or parsing the portable meeting. Delivery uses a persistent outbox with retries, HMAC signatures and a configurable event allow-list.
- Webhook URL, secret, allow-list and timeout live in the operator's persisted settings, so enabling, rotating or changing them does not require recreating the ExApp.
