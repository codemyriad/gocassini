### Added

- Added opt-in signed lifecycle webhooks: `recording.started`, `recording.stopped`, `recording.published`, `recording.failed`, `summary.completed` and `summary.failed`. A `summary.completed` event carries the summary Markdown, so an external workflow can post it without polling or parsing the portable meeting. Delivery uses a persistent outbox that retries for up to 24 hours, HMAC signatures and an event allow-list.
- The receiver URL, secret, allow-list and request timeout are set with `PUT operator/settings/webhook`, so enabling, rotating or changing them does not require recreating the ExApp. The secret is write-only: the API never returns it. See `docs/events.md`.
