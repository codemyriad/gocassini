### Added
- A recording published on its own — in a static export, or embedded in any page — now shows the tags and marked stretches that are inside it, read from the file rather than from a server.
- `<cassini-meeting src="…">` embeds one recording in any page from a single script tag, served from `gocassini.com/embed/v1/viewer.js`. The attribute contract is `cassini-viewer/ATTRIBUTES.md`.

### Changed
- A public viewer is read-only by construction: the marks in a recording are drawn, and no control that would add or remove one is shown. Previously the viewer hid tags entirely when there was no operator to write them.
- Tags that no vocabulary knows — every tag in a recording read on its own — are dealt distinct colours from the palette instead of each hashing its own id, which collided often enough to show several tags in one colour.
