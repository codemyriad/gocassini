### Fixed
- Opening the Doctor panel no longer runs the checks. It shows what the last check found, and the checks run when you ask for them — with the button, or a row's own.
- An archive whose only shortfall is a recording with no words in it now reads as covered. An empty recording is a normal outcome, and no amount of re-indexing can add words to it.
- Removed the "Test recording" row, whose only action sent you to the Talk connection row. Verifying with a test recording is still offered where it is the actual remedy.
