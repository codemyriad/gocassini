### Changed

- A run's detail in the Operator shows what you check a run for — when it was recorded and for how long, how long processing took, the capture mode, why the recording stopped, and links to the conversation in Talk and the recording in Files. The run id, bookkeeping timestamps and each attempt's artifact and log paths are folded under "Technical details", and the provider and the attempt and rerun counts are gone. Each attempt now says how long it took to process, and the run list says when each meeting was recorded rather than when its run last changed.
