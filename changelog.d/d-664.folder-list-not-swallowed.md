### Fixed
- An unreadable Team-folder list is no longer read as "there is no Cassini Team folder". Nextcloud answers with every folder on the instance in one response, and a single unrelated folder in a shape Cassini did not expect made the whole list fail to decode — which looked identical to an empty one. On an installation that really was access-controlled, that turned into the default storage model reporting itself healthy and serving the entire archive to every signed-in account. Cassini now treats a list it cannot read as an unanswered question and refuses to publish until it gets an answer, which is what it already did when Nextcloud was unreachable.
