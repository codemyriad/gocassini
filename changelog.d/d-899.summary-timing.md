### Changed

- A run's Summary step now shows how long the summary took, even when it was written during the build, and the Build step no longer includes that time. The run's processing figure ("10m · 5.8× real time") leaves the summary out too, so a slow summary model no longer looks like a server that can't keep up; hover it to see how long the summary took. Meetings processed before this update show the run as they did.
- The meeting file records when its summary was written (`processing.meetingSummary.startedAt` and `finishedAt`).
