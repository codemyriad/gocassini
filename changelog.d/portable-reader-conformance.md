### Fixed
- Portable `.opus` files whose chunk sets carry base64url `=` padding now read. Producers write the encoding unpadded, but most base64url encoders pad by default, so a file written by another implementation was rejected outright as invalid metadata.
- A transcript's chunk count and the default transcript now come from the manifest rather than from the `CASSINI_TX_*_CHUNK_COUNT` and `CASSINI_TRANSCRIPT_DEFAULT` tags that mirror it. A file whose two layers had drifted lost a transcript that was entirely present, returned a silently truncated one, or served a different transcript than the manifest names; the disagreement is now reported and the file still reads.
- `cassini inspect` reports the word count it actually decoded out of a portable `.opus`, names any transcript whose body it could not read, and exits non-zero. It used to print the manifest's declared `words=900` and `cassini=ok` for a file whose transcript was unreachable.
- A meeting's `words=` is the default transcript's count rather than the sum across every transcript in the file. Alternative transcripts are further passes over the same speech, so a three-word meeting published with two passes was reported as six words.
