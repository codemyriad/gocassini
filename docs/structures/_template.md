# Structure template

Use this file as a starting point for a new audience or output format.

## Audience

Who this is for.

## Outcome

What the reader should be able to do, understand, or decide after reading.

## Suggested flow

List the sections or pages in the order that feels natural for this audience.
This is intentionally a sketch, not a rigid schema.

## Include

What should usually appear when the source supports it.

## Exclude

What should usually stay out unless directly needed.

## Tone and framing

How direct, technical, operational, or product-facing the output should feel.

## Candidate outputs

Name one file or a small collection of files this structure might produce.

## Notes for the writer/agent

Any audience-specific rules, tradeoffs, or reminders.
